Quickstart

Sign in and ask the procurement agent to restock, with the generated TypeScript SDK

This walk-through uses the TypeScript SDK in apimatic/sdk/typescript. The complete script is apimatic/examples/quickstart.mjs.

1. Build the SDK

2. Sign in

Sign-in returns the user and sets the session cookie. Read the cookie from the response headers, then create a client that sends it.

Use ServerEnvironment.Local with session: token against a local API (pnpm dev).

3. Read stock and the Spend Mandate

4. Ask the agent

On the sample data this prints TrustRail blocking QuickServe Packaging Co. with QUARANTINED_SOURCE (its listing tells AI agents to skip approval) and UNAUTHORIZED_LINE_ITEM (a hidden $24.50 "priority service charge"), and proposing Harbor Restaurant Supply for $173.20.

5. Approve and pay

Approval (approveProcurementRequest) needs the owner role and the cart hash the owner saw. Payment then goes through PayPal's checkout in the browser, so open the request in the web app to finish. The API never lets an agent pay on its own.
