Quartermaster is a procurement agent for restaurants. An owner writes _"We're expecting a busy
weekend. Restock takeaway containers and cooking oil without exceeding $300."_ The agent
forecasts demand, compares suppliers with Channel3 market prices and proposes carts.
**TrustRail** checks every cart in code against the owner's Spend Mandate, blocking hidden fees
and prompt-injected listings. PayPal then captures payment only after the owner approves one exact,
signed cart.

This portal, the TypeScript and Python SDKs and the agent-friendly docs are generated by APIMatic
from the API's [OpenAPI 3.1 spec](https://github.com/pranavsaji/quartermaster-ai/blob/main/docs/openapi.json).
A contract test checks that spec against the API's real responses.

## Conventions

- **Money** is always integer minor units (cents): fields end in `_minor`.
- **Sign-in** sets an httpOnly session cookie: `__Host-qm_session` on the hosted demo, `qm_session` locally.
- **Every mutation** sends `X-Requested-With: quartermaster` (CSRF guard). Approval and payment calls
  also take an `Idempotency-Key`, so a retry never pays twice.
- **Errors** share one shape, `ApiError`, with a stable `code` and a fixed message.
- **Roles:** owners approve and pay, managers request and research, viewers read.
- **Payments** run in the PayPal sandbox only. No real money moves.
